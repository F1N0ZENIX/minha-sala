Configurar Firebase

Para sincronizar dados entre todos os dispositivos:

1. Acesse firebase.google.com e faça login com sua conta Google
2. Clique em "Criar projeto" → nomeie (ex: "minha-turma")
3. No menu lateral: Realtime Database → Criar banco de dados → escolha "Modo de teste"
4. Clique no ícone ⚙️ Configurações do projeto → guia "Geral" → role até "Seus apps" → clique no ícone </> (Web) → copie o objeto firebaseConfig
5. Cole abaixo (apenas o conteúdo entre chaves {...})
